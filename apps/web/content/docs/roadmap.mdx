Galena has no release yet. Everything elsewhere in these docs describes what works today; this
page is the only place that describes what doesn't yet.

## Next: ecosystem

- **Webhook endpoints, fully.** A delivery log, replay, a longer retry schedule and automatic
  disabling after three days of failures.
- **API keys.** Scoped `read`, `write` and `admin` keys for scripts.
- **Members.** Inviting members, changing roles, and GitHub sign-in in the dashboard.

## Version 1.0

- An internal status page that needs a signed-in session.
- A security pass with a written threat model.
- Metrics, alarms and an external dead-man's switch.
- Load tests of the status page.
- A self-hosting guide tested by someone who has never seen the project.

## After 1.0

- More monitor types: TCP, DNS, certificate and domain expiry, heartbeats.
- Discord and Microsoft Teams.
- A GitHub App: deploys and merged pull requests on incident timelines.
- Importing from Statuspage.
- iCal for maintenance, and a JSON feed.
- Grafana, CloudWatch and Sentry as alert sources.
- Checks more often than once a minute.
- A TypeScript SDK and a CLI.
