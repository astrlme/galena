---
title: Apache-2.0, single tenant
description: Why Galena is permissively licensed and deploys one workspace per account.
---

## Problem

Several open-source status pages use AGPL-3.0, which many companies avoid. Hosting many tenants
adds isolation, billing and noisy-neighbour work that doesn't help someone running their own copy.

## Decision

License under Apache-2.0, which includes an explicit patent grant. Deploy one workspace per
installation, into the operator's own AWS account. Every table still carries `workspace_id`.

## Alternatives

| Option | Why not |
| --- | --- |
| AGPL-3.0 | Discourages adoption and embedding |
| MIT | No patent grant |
| A multi-tenant service | Scope, cost and security surface |

## Consequences

- No hosted offering to maintain.
- Adding tenancy later means scoping sign-in and filtering rows, not rewriting the schema. See
  [Global identity tables](/docs/decisions/identity-tables/).

## Revisit when

There is demand for a hosted version.
